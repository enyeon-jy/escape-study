# 탈출 스터디

강의자료를 넣으면 테마에 맞는 자극적인 단서(수상한 쪽지, 기밀 문서, 엿들은 대화 등)와 자물쇠로 이루어진 방탈출 게임을 만들고, 탈출 후 복습 모드로 기억을 굳히는 학습 서비스 (제작 중)

서비스 이름은 **시험범위에 갇혔다**. 자세한 기획은 [docs/요구사항.md](docs/요구사항.md)를 참고하세요.

## 체험하기
👉 **https://escape-study-alpha.vercel.app** (Vercel 무료 Hobby 배포, main에 push하면 자동 배포)

## 화면 흐름
1. 시작·자료 넣기 (테마·난이도·게임 길이 선택)
2. 1인칭 탐색형 방탈출: 벽 3면을 ← → 로 돌아보고, 책상·책장·캐비닛은 눌러서 클로즈업한다. 단서는 수첩에, 열쇠 같은 아이템은 가방에 모이고, 앞 벽의 문 자물쇠(숫자·알파벳 다이얼, 키패드, 방향)를 손으로 돌려 푼다. 방마다 타이머와 힌트가 있다.
3. 탈출 결과
4. 복습 모드: 이번 게임에서 다룬 개념을 빈칸 문제로 다시 풀고, 틀린 문제는 맞힐 때까지 반복한다.

진행 상황과 이미 만든 방은 브라우저(localStorage)에 저장되어 "이어하기"가 가능합니다. 게임 데이터(과목명·테마·난이도·방 JSON)와 플레이 결과는 Supabase 무료 요금제에도 저장하며, 개인정보와 강의자료 원문은 저장하지 않습니다. 설정 방법은 [docs/supabase.md](docs/supabase.md)를 보세요.
효과음은 소리 파일 없이 Web Audio로 만들고, 배경 이미지는 `public/backgrounds/공포.png` 등을 넣으면 바로 쓰입니다.
난이도·방 개수·자료 글자 수 같은 숫자는 `lib/config.ts`에서 조절합니다.

## 실행 방법
```bash
npm install
npm run dev
```
브라우저에서 http://localhost:3000 을 엽니다.

AI로 방을 만들려면 `.env.local`(GitHub에 올라가지 않음)에 값을 넣어야 합니다. 목록은 `.env.example` 참고.
```
OPENAI_API_KEY=학교 FactChat 키
OPENAI_MODEL=학교 플랫폼에서 확인한 모델 ID
```
키는 서버(API 라우트)에서만 쓰이고 화면 코드에는 들어가지 않습니다.
