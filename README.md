# 탈출 스터디

강의자료를 넣으면 테마에 맞는 자극적인 단서(수상한 쪽지, 기밀 문서, 엿들은 대화 등)와 자물쇠로 이루어진 방탈출 게임을 만들고, 탈출 후 복습 모드로 기억을 굳히는 학습 서비스 (제작 중)

서비스 이름은 **시험범위에 갇혔다**. 자세한 기획은 [docs/요구사항.md](docs/요구사항.md)를 참고하세요.

## 체험하기
👉 **https://escape-study-alpha.vercel.app** (Vercel 무료 Hobby 배포, main에 push하면 자동 배포)

## 화면 흐름
1. 시작·자료 넣기 → 2. 방탈출(방 3개, 타이머, 힌트) → 3. 탈출 결과 → 4. 복습 모드(빈칸 문제, 틀린 문제 반복)

## 실행 방법
```bash
npm install
npm run dev
```
브라우저에서 http://localhost:3000 을 엽니다.

## 현재 진행 상황
- [x] 1단계: AI 연결 없이 예시 데이터로 화면 4개 흐름

- [ ] 3단계: 교수님 등장 연출
- [ ] 4단계: AI 연결 (FactChat)
- [ ] 5단계: 이세계·추리 테마, PDF 올리기

## 기술
Next.js(TypeScript), Vercel(무료 Hobby). 정답 확인·타이머·결과 계산은 AI가 아니라 코드가 합니다.
