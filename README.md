# 탈출 스터디

강의자료를 넣으면 테마에 맞는 자극적인 단서(수상한 쪽지, 기밀 문서, 엿들은 대화 등)와 자물쇠로 이루어진 방탈출 게임을 만들고, 탈출 후 복습 모드로 기억을 굳히는 학습 서비스 (제작 중)

서비스 이름은 **시험범위에 갇혔다**. 자세한 기획은 [docs/요구사항.md](docs/요구사항.md)를 참고하세요.

## 체험하기
👉 **https://escape-study-alpha.vercel.app** (Vercel 무료 Hobby 배포, main에 push하면 자동 배포)

## 화면 흐름
1. 시작·자료 넣기 (테마·난이도·게임 길이 선택)
2. 탐색형 방탈출: 방 안의 물건을 눌러 단서를 모으고, 단서를 조합해 문/금고의 답을 알아낸다. 방마다 타이머와 힌트가 있다.
3. 탈출 결과
4. 복습 모드: 이번 게임에서 다룬 개념을 빈칸 문제로 다시 풀고, 틀린 문제는 맞힐 때까지 반복한다.

진행 상황과 이미 만든 방은 브라우저(localStorage)에만 저장되어 "이어하기"가 가능하고, 서버 DB는 쓰지 않습니다.
난이도·방 개수·자료 글자 수 같은 숫자는 `lib/config.ts`에서 조절합니다.

## 실행 방법
```bash
npm install
npm run dev
```
브라우저에서 http://localhost:3000 을 엽니다.
